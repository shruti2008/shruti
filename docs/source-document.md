# Product Update: Knowledge Hub

The Knowledge Hub project centralizes technical guides, release notes, and API documentation in one place.
Before this work, teams searched through many scattered pages and often duplicated information.
The new indexing pipeline tags each document by product area, audience, and release window.
Search relevance has improved, and new team members can now locate onboarding guides within minutes.
Writers also spend less time answering repeated questions because key links are easier to discover.
The next phase introduces automated summary generation so each long document can publish a concise companion summary.
